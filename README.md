# Zechung｜AI 創作集

Zechung 的繁體中文 AI 作品集，收錄網站工具、角色設計、動畫、聲音實驗與工作流程。

公開網站：https://zechunghk.github.io/zechung-ai-portfolio/

網站以 HTML、CSS 和 JavaScript 製作，圖片、影片與音樂放在 `assets/`。GitHub Pages 從 `main` 分支的根目錄發佈；更新網站檔案並推送後會自動重新部署。

17 個項目的詳解收錄在 `project-details.js`，包括主要功能、製作流程、使用情境及 AI／人手分工；`project-details.css` 負責詳解版面。項目可用 `#project-zefnba`、`#project-subtitle` 等連結直接開啟。新增內容以文件與既有作品為依據，情境示例不包含私人紀錄。

此儲存庫只包含作品集展示內容；各項目的原始程式庫以網站內提供的公開連結為準。
